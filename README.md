# 🎮 Kleine Lernspiele

Interaktive Lernspiele als standalone HTML-Dateien — kein Server, keine Installation, einfach öffnen und spielen.

👉 **[raphaelfisch.github.io/spiele](https://raphaelfisch.github.io/spiele/)**

---

## Spiele

| Spiel | Beschreibung |
|-------|-------------|
| 🎯 [Dobble](dobble.html) | Finde das gemeinsame Symbol auf zwei Karten — mit Themen, Levels und Timer |
| ⚡ [Energiemanager](energiemanager.html) | Energie und Nachhaltigkeit spielerisch entdecken |
| 🎲 [Hose abe](hose-abe.html) | Würfelspiel für den Unterricht |
| 🃏 [Jasskarten](jasskarten.html) | Spiele mit Schweizer Jasskarten im Browser |
| 🧩 [Tectonic](tectonic.html) | Zahlen-Puzzle für logisches Denken |

## Verwendung

Jedes Spiel ist eine einzelne `.html`-Datei — einfach im Browser öffnen, kein Internet nötig (ausser für Schriftarten).
